# Rext AI backend

The API and the content-generation graph behind [Rext AI](https://rext.ai): a marketer types a keyword, and the backend researches the search results, recommends a content type, proposes titles and an outline, and writes the article, stopping at four points for the person to choose. It also holds the accounts, workspaces, plans and credits, and publishes to WordPress.

- **The server:** FastAPI, mounted as the HTTP app of a LangGraph server (`langgraph.json`). The graph is `main:graph`, built in `src/flow/engines/rext.py`.
- **Data:** PostgreSQL with pgvector (SQLAlchemy 2 with Alembic migrations) and Redis.
- **Outside services:** OpenAI, DataForSEO, Tavily, Lemon Squeezy, Resend and MinIO.
- **Clients:** the dashboard ([revnix/rext-admin](https://github.com/revnix/rext-admin)) and the Shopify app in `rext/`.

## Quick start

Python 3.11 and [uv](https://docs.astral.sh/uv/). Start PostgreSQL with pgvector and Redis first, as `DEVELOPMENT.md` describes.

```bash
uv sync --frozen
cp .env.example .env                                # then fill in the names at the top
uv run python scripts/db.py migrate                 # migrations, the LangGraph store's tables, the seed data
uv run langgraph dev --no-browser --port 2024       # the API and the graph; /docs lists the endpoints
```

## Branches and deploys

`stage` is the base branch. A merge into it deploys staging, and a push to `main` deploys production (`.github/workflows/`). Every change goes through a pull request into `stage`.
